 L'art du prompt


## 1. Objectif de la tâche 

L'objectif est d'expliquer le Machine Learning à un étudiant de première année universitaire qui débute en intelligence artificielle. La réponse doit être simple, claire et accompagnée d'exemples concrets.

## 2. Tester et améliorer le prompt

### Prompt initial

Explique le Machine Learning.

### Résultat obtenu

Le Machine Learning (apprentissage automatique) est une branche de l’intelligence artificielle (IA) qui permet à un ordinateur d’apprendre à partir de données et d’améliorer ses résultats sans être programmé manuellement pour chaque situation.

Comment fonctionne le Machine Learning ?
1. Collecte des données

On fournit des exemples à l’ordinateur.

2. Apprentissage

L’ordinateur analyse les données et repère des modèles.

3. Prédiction

Il utilise ce qu’il a appris pour analyser de nouvelles données.

Exemples concrets
Exemple

Utilisation du Machine Learning

YouTube

Recommande des vidéos selon tes intérêts.

Gmail

Détecte les courriers indésirables (spam).

Reconnaissance faciale

Identifie un visage à partir de caractéristiques apprises.

Jeux vidéo

Peut adapter le comportement des adversaires.

Les principaux types de Machine Learning
Apprentissage supervisé : l’ordinateur apprend à partir d’exemples étiquetés. Exemple : reconnaître les chats et les chiens sur des images identifiées.

Apprentissage non supervisé : l’ordinateur cherche des groupes ou des structures dans des données non étiquetées. Exemple : regrouper des clients selon leurs habitudes.

Apprentissage par renforcement : l’ordinateur apprend par essais, erreurs et récompenses. Exemple : apprendre à un agent à jouer à un jeu.

Quelle est la différence entre l’IA et le Machine Learning ?
Intelligence artificielle (IA) : domaine général qui vise à créer des systèmes capables d’effectuer des tâches associées à l’intelligence humaine.

Machine Learning (ML) : sous-domaine de l’IA qui apprend des modèles à partir de données.

À retenir : le Machine Learning permet à une machine d’apprendre des modèles à partir de données afin de réaliser des prédictions ou de prendre des décisions.



### Prompt amélioré

Tu es enseignant en informatique. Explique le Machine Learning à un étudiant de L1 qui débute en intelligence artificielle. Donne une définition simple, deux exemples concrets et une comparaison avec le Deep Learning. Utilise un langage facile à comprendre, limite la réponse à 150 mots et organise-la avec trois sous-titres.

### Résultat obtenu

Le Machine Learning (apprentissage automatique) est une branche de l’intelligence artificielle qui permet à un ordinateur d’apprendre à partir de données pour réaliser des prédictions ou prendre des décisions, sans programmer chaque règle manuellement.
2. Deux exemples concrets
- Filtrage des spams : Gmail apprend à reconnaître les courriers indésirables en analysant des exemples de messages.
- Recommandation de vidéos : YouTube analyse les vidéos regardées pour proposer des contenus susceptibles de t’intéresser.
3. Comparaison avec le Deep Learning
Le Deep Learning (apprentissage profond) est une sous-catégorie du Machine Learning qui utilise des réseaux de neurones artificiels comportant plusieurs couches.
- Machine Learning : peut utiliser des méthodes simples et nécessite parfois de sélectionner les caractéristiques des données.
- Deep Learning : apprend automatiquement des caractéristiques complexes et est particulièrement utile pour les images, la voix et le langage.
À retenir : le Deep Learning fait partie du Machine Learning, qui fait lui-même partie de l’intelligence artificielle.
